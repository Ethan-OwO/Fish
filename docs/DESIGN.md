# seastate-app — 海上儀表 / Marine Instrument

改編自 ClickHouse「Data-Dense Pro」。保留其資訊密度、等寬數字、扁平深色的工程感;
但把場景從「辦公室桌機看幾千列」換成「甲板上單手看一個判斷」,因此字級、觸控目標、對比度全數上調。

---

## 1. Visual Theme & Atmosphere

**海上儀表。** 參考對象不是 SaaS dashboard,是船用航儀:海圖機、測深儀、AIS 螢幕。
深藍墨底、發光數值、無裝飾。

一個原則凌駕一切:**使用者打開 App 只想在 2 秒內知道「今天能不能出海」。**
其餘所有數據都是這個判斷的佐證,不是並列資訊。

Mood: 儀器、可信、不囉唆。不做行銷感,不做療癒感,不做插畫。

---

## 2. Color Palette & Roles

背景改成**藍墨**而非中性炭灰——深色階梯直接沿用海圖的水深分層概念:越淺 = 越靠近使用者 = 越前景。

```
/* 深色(預設)—— 水深分層 */
--bg:              #0b1620   /* 深水 */
--bg-alt:          #11202b   /* 陸棚 */
--surface:         #1a2f3c   /* 淺灘 */
--surface-hi:      #24404f   /* 潮間帶,hover / pressed */
--border:          #21384a

--text:            #eaf2f6
--text-muted:      #9ab0bd
--text-dim:        #5f7686

--accent:          #35d6e8   /* 儀表青 —— 互動、連結、選取態 */
--accent-alt:      #ff6b2c   /* 救生橘 —— 只給「送出回報」CTA(M6) */
```

### 評級三色(語意專用,禁止挪作他用)

```
--safe:            #5ce08a
--caution:         #ffc233
--danger:          #ff4d5e

--safe-bg:         #0f2a1e   /* 評級燈底 */
--caution-bg:      #2e2412
--danger-bg:       #2e1418
```

> **為什麼強調色不是黃色。** 原版招牌黃 `#faff69` 與 `--caution` 同色相,一旦按鈕、連結、圖表都是黃的,
> 「注意」這個語意就被稀釋。這裡把強調色移到儀表青(不帶任何嚴重度語意),
> 黃/綠/紅三色**全站只出現在評級語境**。看到黃色 = 有事。

### 量測色綁定(取代原版的通用 categorical palette)

海況只有固定幾個物理量,不需要 8 色輪替。**一個量一個色,全站永不變**:

```
--m-wind:          #35d6e8   /* 風速 */
--m-gust:          #35d6e8   /* 陣風 —— 同色,虛線區分 */
--m-wave:          #7aa2ff   /* 浪高 */
--m-temp:          #ff9b54   /* 海表溫 */
--m-warning:       #ff4d5e   /* CWA 警特報 */
```

使用者建立的是肌肉記憶:「藍紫那條是浪」。輪替色票會摧毀這件事。

### 日照模式(高亮度,非選配)

正午甲板上,深色主題實測不可讀。提供 `[data-theme="sun"]`,並在設定裡給明確開關(不要只靠系統偏好):

```
--bg:       #ffffff
--bg-alt:   #eef3f6
--surface:  #e2eaef
--border:   #b9c8d2
--text:     #0b1620
--text-muted: #47606f
--accent:   #0a7f8c
--safe:     #0f7a3d
--caution:  #9a6200
--danger:   #c1121f
```

三色在淺底上必須**加深**而非沿用深色版,否則對比度不足。日照模式下評級燈改為**滿版色塊 + 深色文字**,追求純粹的面積對比。

## 3. Typography Rules

- **中文 UI:** `Noto Sans TC`,weight 400 / 500 / 700。
- **拉丁與數字:** `Inter`,`font-variant-numeric: tabular-nums` **一律開啟**。
- **數值 / 座標 / ID / 時間:** `JetBrains Mono`。

> **CJK 陷阱:** JetBrains Mono 沒有中文字符,整句中文丟進 mono class 會 fallback 成醜的等寬 CJK。
> Mono 只包**數字、單位、經緯度、時間戳**;中文標籤留在 Noto Sans TC。
> 正確:`<span class="mono">4.2</span> m 浪高` / 錯誤:`<span class="mono">浪高 4.2 m</span>`

Scale:`13 / 14 / 16 / 18 / 22 / 28 / 40 / 64`

原版 11–13px 全數上移。**14px 是可讀性下限**,不是預設;正文用 16。
`40 / 64` 專供評級燈與主要數值——這兩級在原版並不存在,是本專案新增的。

## 4. Component Stylings

### 評級燈 RatingLight —— 招牌元件

首屏最大的物件,單一色塊,佔 mobile 首屏約 40% 高。內含:等級中文字(28px/700)+ 一句白話結論。

嚴重度用**三種通道同時編碼**,不只靠顏色(色盲、強光下色彩失真都會發生):

| 等級 | 色 | 邊框 | 燈質(參考海圖燈標寫法) |
|---|---|---|---|
| 安全 | `--safe` | 1px 實線 | 定光 Iso —— 靜止不動 |
| 注意 | `--caution` | 2px 實線 | 明暗光 Oc —— 2.4s 呼吸,opacity 1 → 0.6 |
| 危險 | `--danger` | 3px 雙線 | 閃光 Fl(2) —— 4s 週期雙閃 |

`prefers-reduced-motion` 下取消動畫,邊框差異與文字獨立成立。動畫是加分項,不是唯一資訊通道。

### 數值卡 MetricCard

```
浪高                    ← 13px, --text-muted
4.2 m                   ← 40px mono + 16px 單位
大浪                     ← 16px, 該因子的評級色
```

數值 mono、右側或下方掛人類可讀分級(蒲福 X 級 / 浪級中文)。
`evaluate.ts` 已經產出 `DangerFactor.label`,**直接用它**,不要在前端重新造句。

### 新鮮度標記 StalenessBadge

`/api/sea-conditions` 回的 `is_stale` / `staleness_seconds` 是**一級 UI 概念**,不是角落小字:

- 新鮮(< 30 分):`--text-dim` 小字「10 分鐘前更新」。
- 過期(`is_stale`):`--caution` 外框 pill,置於評級燈**正下方**,文案「資料是 2 小時前的,海上狀況可能已改變」。
- 冷啟動 / 全失敗:整張卡降級為 `--surface` 灰,評級燈**不顯示顏色**,顯示「目前取不到資料」。

> 絕不用舊資料撐出一個綠色的「安全」。過期時寧可退掉顏色。

### 空值與降級 —— 對應決策 6

陸地座標的 `waveHeight` 會是 `null`。

- `null` 一律顯示 `—`(`--text-dim`),**永遠不要渲染成 0**。0 在這裡的意思是「無浪」,是致命誤讀。
- 該量缺漏時,對應的 factor 從清單移除並附註「浪高資料不涵蓋此座標」,不參與 max 運算的視覺呈現。
- 部分來源失敗仍可出評級 → 標題旁掛小 pill:「以 2/3 來源判定」。

### 因子清單 FactorList

`DangerResult.factors` 逐列渲染。每列:左 8px 圓點(該因子自身 level 色)+ 中文 label + 右側 mono 原始值。
**列高 44px**,不是原版的 28px——手指不是滑鼠。

### 地圖(Leaflet, M4)

- 深色海圖底圖,陸地壓暗到近 `--bg-alt`,海面留亮。
- Zone 多邊形:`fill` 用評級色 12% alpha,`stroke` 同色 60%,1px。選中時 stroke 加粗至 2px。
- 使用者選點:儀表青十字準星 + 下方 mono 顯示經緯度(可長按複製)。
- **圖層架構從第一天就要可插拔**——M6 的魚訊圖層要能直接掛上,不是重寫。

### 表格(海域清單)

沿用原版:sticky header、數值右對齊、每欄可排序、zebra 用 `--bg-alt`。
唯一改動:列高 **44px**(原 28–32)。桌面版可提供「密集模式」切回 32px。

### 按鈕

- Primary:`--accent` 填色 + 深色文字,radius 4px,**min-height 44px**,水平 padding 16px。
- 回報 CTA(M6):`--accent-alt` 填色。全站唯一的橘色,因此不會誤按。
- Secondary:`--surface` 填色 + 1px `--border`。
- 相鄰按鈕間距 ≥ 8px(濕手誤觸緩衝)。

### 輸入框

`--bg-alt` 填色、1px `--border`、radius 4px、**min-height 44px**。
經緯度輸入用 mono + `inputmode="decimal"`。

### 徽章

Pill、24px 高(原 20px)、mono、大寫。只用於狀態,不用於裝飾。

### 免責聲明 Disclaimer

常駐,**不可關閉**。置於評級區塊正下方(不是頁尾——沒人捲到頁尾)。
`--text-muted`、13px、1px 上框線。文案直白:「本評級為參考值,非官方法定標準,出海前請以中央氣象署發布為準。」

## 5. Layout Principles

- 4px grid 保留。觸控目標另立規則:**最小 44×44**,兩者不衝突。
- **Mobile(主要場景):** 單欄。由上而下 — 地點列 → 評級燈 → 新鮮度 → 數值卡 2×2 → 因子清單 → 免責 → 地圖入口。
- **地圖頁:** 全屏地圖 + 底部 bottom sheet(可拉起)。收合時只露評級燈與地點名。
- **Desktop:** 地圖為主 + 右側 360px 面板(可收合)。不做 12 欄儀表板。
- 首屏內必須同時看見:**地點、評級、資料時間**。這三個少一個,判斷就不成立。

---

## 6. Depth & Elevation

扁平。深度靠水深色階(`--bg` → `--bg-alt` → `--surface` → `--surface-hi`)。
陰影只給 bottom sheet、下拉與 modal。
評級燈**不加陰影**——它靠面積和顏色贏,不靠浮起。

---

## 7. Do's and Don'ts

**Do**
- 讓評級在首屏一眼可見,其餘皆為佐證。
- 數字、座標、時間一律 mono + tabular-nums。
- 嚴重度同時用色 + 邊框 + 動態編碼。
- 資料過期時退掉顏色,而不是照樣顯示綠色。
- 文案講漁民的話,不講系統的話。

**Don't**
- 不要把 `null` 渲染成 `0`。
- 不要用綠/黃/紅做任何非評級用途。
- 不要用襯線體。
- 不要把數值置中對齊。
- 不要為了資訊密度把觸控目標縮到 32px 以下。
- 不要在核心海況檢視路徑上出現任何登入牆(M6 也一樣,只擋「送出回報」)。

## 8. Responsive Behavior

**與原文相反:本專案手機優先,而且不為此道歉。**
使用者站在船上、單手、逆光。桌面版是輔助檢視工具,不是主場。

- Mobile 首屏 = 一個評級 + 一個地點 + 一個時間。其餘捲動取得。
- 橫向不特別優化(甲板上沒人橫拿)。
- 觸控目標與間距在任何斷點都不縮小。

## 9. Agent Prompt Guide

**Bias:** 深藍墨底、儀表青強調色、評級三色專用、tabular-nums、數字用 mono 中文用黑體、4px grid、44px 觸控目標、手機優先、評級燈為首屏主體、新鮮度與免責常駐。

**Reject:** 黃色當品牌色、通用輪替色票、`null` 顯示為 0、襯線體、行銷插畫、英雄式漸層、把評級色挪作裝飾、32px 以下的觸控目標、核心檢視路徑上的登入牆。

## 10. 狀態矩陣(補充)

前端必須把這張表當作真值表實作,不是靠 if-else 隨手拼:

| 資料狀態 | 評級燈 | 新鮮度標記 | 數值卡 |
|---|---|---|---|
| 新鮮 + 完整 | 對應色 + 燈質 | 灰字「N 分鐘前」 | 全數顯示 |
| 新鮮 + 部分來源缺 | 對應色 + 燈質 | 灰字 + 「以 N/3 來源判定」 | 缺項顯示 `—` |
| `is_stale` | 對應色但**降低飽和** | 黃框警示 + 實際時間 | 全數顯示,加時間戳 |
| 冷啟動載入中 | 骨架動畫 | 「取得中」 | 骨架 |
| 全部失敗 | 灰色 + 「取不到資料」 | 「上次成功:—」 | 全 `—` |

## 11. 現場條件與無障礙(補充)

- **強光:** 日照模式必須有手動開關,不能只跟隨系統。深色模式正文對比度 ≥ 7:1。
- **濕手 / 手套:** 44px 最小目標、8px 間距、不用長按作為唯一操作方式。
- **色覺:** 三級評級的顏色差異**永遠有非色彩備援**(邊框粗細 + 燈質 + 中文字)。紅綠色盲用戶只看文字也能用。
- **老花:** 評級燈與主要數值在 200% 系統字級下不得截斷或溢出。
- **離線:** M8 PWA 上線後,離線顯示最後一次快取並強制標為過期。

## 12. 文案語氣(補充)

寫給漁民,不是寫給工程師。**用結果說話,不用系統詞彙說話。**

| 不要 | 要 |
|---|---|
| API 錯誤 (500) | 資料暫時取不到,顯示 2 小時前的紀錄 |
| `is_stale: true` | 這筆是 2 小時前的,海況可能已經改變 |
| 危險 | 危險 — 目前不建議出海 |
| 無資料 | 這個位置沒有浪高資料,請選外海座標 |

- 動詞用主動式,同一個動作全流程同名(按鈕寫「送出回報」→ toast 就寫「回報已送出」)。
- 錯誤訊息說明**發生什麼**與**怎麼辦**,不道歉、不含糊。
- 三個評級各配一句白話結論,長度控制在 12 字內,一行放得下。
